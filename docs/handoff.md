Any distributed ES-DE-Plus APK is therefore a GPL-2.0 combined work even though the repository is MIT. Options: (a) accept — distribute the APK under GPL-2.0 terms with full corresponding source (which is already public), add a plain statement to `README.md` and the Android project that the APK as a whole is GPL-2.0 while the ES-DE-Plus source stays MIT; (b) drop PDF manual viewing on Android — remove the `es-pdf-convert` link from the Android target (small upstream CMake and `PDFViewer.cpp` guard) so the APK is MIT/LGPL/zlib only, losing a feature upstream has; (c) replace Poppler with a permissively licensed renderer on Android (PDFium, BSD) — a separate slice of real size. Fable recommends (a). Until ruled: CI builds and tests the APK with Poppler in process exactly as upstream does, FFmpeg is built without GPL components, Sol records the shipped licence inventory, and nothing is distributed. Resume action: record `D-004`; for (a) add the statement; for (b) or (c) open a slice.
