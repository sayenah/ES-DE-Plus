Acceptance criteria (Astra's wording adopted):
- AC-1 The configurator offers scoped storage and explicit direct-filesystem compatibility before requesting broad access. Both accepted modes provide a demonstrated user-accessible way to populate the ROM directory. Shared-directory selection persists granted tree permissions, resolves only supported providers and current-user volumes, and verifies the native filesystem access required by the selected directories. Unsupported providers, unavailable capabilities, permission denial and cancellation produce recoverable outcomes without silently changing selections.
- AC-2 Normal, HOME and Leanback entry points start or reuse the intended single SDL activity. Cold launch, warm re-entry and configurator return preserve the documented HOME-state semantics and corresponding Back/quit behaviour. Leanback configuration is operable with a D-pad. Missing picker or all-files-settings capabilities produce the documented fallback.
- AC-3 Configurator cancellation, revoked storage access, an unavailable selected volume and interrupted or failed resource copying are exercised. None causes an indefinite native hold, silent data-directory substitution, destructive migration or an unrecoverable HOME restart loop. Returning to a valid configuration permits startup.
- AC-4 The API-29 legacy-storage path and the API-30+ all-files path have recorded runtime evidence (x86_64 images API 29 and API 34). TV evidence (an Android TV x86 image, API 30 or later) demonstrates D-pad configuration and capability handling. Each run drives the real screens through host-side UI automation with no preference injection.
- AC-5 On each image the frontend reaches the rendered system view after configuration against a shared ROM directory (compatibility mode) and against the app-owned directory (scoped mode), with screenshots and logs; restart preserves the configuration.
- AC-6 PR-A's AC-2 (desktop unchanged, formatting), AC-6 (bridge correctness), AC-8 (B-5) and AC-9 (cache pair) hold at the PR-B head; the identity audit passes; no new dependency.
